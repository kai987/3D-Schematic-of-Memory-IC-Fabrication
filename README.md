# 東広島 Fab15 — DRAMウェーハ製造工程の3D学習モデル

マイクロンの公開資料を根拠に、東広島のFab15のウェーハ製造に関係する工程区分を学ぶ日本語アプリです。公開資料で確認できる範囲、過去の公開記録、模式表現を工程ごとに区別します。マイクロンが公開した実工程図や工場配置図ではありません。

**工程順、反復回数、装置の外観・内部構造・寸法・台数、フロア配置、搬送経路、処理時間、ウェーハ断面、検査位置は説明用の模式表現です。実際の製造レシピ、装置メーカー・型番、実測値、歩留まりは再現していません。**

切断、組立、封止、パッケージ製品の最終試験は、このモデルの対象外です。この除外は、Fab15にそれらの工程が存在しないという断定ではありません。

## 起動する

Node.js 24とnpmで動作を確認しています。

```sh
npm install
npm run dev
```

開発用は `http://127.0.0.1:5173/`、ビルド済みのプレビューは `http://127.0.0.1:4173/` です。

```sh
npm run build
npm run preview
```

`dist/` が静的配信用のビルドです。HTMLを直接ダブルクリックせず、ローカルサーバーから開いてください。

## 使い方

- ドラッグで回転、ホイール・ピンチで拡大縮小、右ドラッグで移動。
- 装置、ラベル、下部の工程区分を選ぶと、公開資料の根拠、未確認事項、学習用解説を表示。
- 「この工程に移動」で選択した装置を拡大。スマートフォンでは3Dビューまでスクロール。
- 「全体」「前工程」「プローブ」で視点を切り替え。「視点を戻す」で全体へ戻る。
- 再生・一時停止、前後の区間、再生位置、0.5×・1×・2×の速度を操作。
- 「工程管理・DXの視点（一般例）」は学習用の一般的なデータ活用例。Fab15の実装を示すものではない。
- 「公開資料・確認範囲」で公開日、証書期限、確認内容、確認できない内容を表示。

## 収録する9つの工程区分

番号は分類用です。実際の工程順を示しません。

| 工程区分 | 主な模式表現 |
| --- | --- |
| ウェーハ搬送 | FOUP、ロードポート、OHT軌道と昇降部 |
| ウェット処理・洗浄 | ウェットステーション、槽、透明窓 |
| 薄膜形成 | 真空チャンバー、ウェーハ、配管 |
| フォトリソグラフィ | 露光装置、塗布現像ユニット |
| ドライエッチング | 処理チャンバー、ロードポート |
| 拡散・イオン注入・熱処理 | ビームライン、処理室、熱処理部 |
| CMP・平坦化 | 研磨ヘッドとパッド |
| 計測・欠陥検査 | 光学ヘッド、ウェーハステージ |
| プローブ検査 | プローブカード、チャック、画面 |

工程のつながりや反復を理解するための模式デモです。デモの経路は `src/data/processes.ts` の `DEMO_ROUTE` に定義します。Fab15の実処理順、回数、時間を推定したものではありません。OHTの台車は軌道上を移動し、FOUPの昇降部だけが上下します。搬送設備の構成自体も一般的な例です。

## 公開資料と確認範囲

- 工程ごとの根拠、公開日、確認日、確認内容、限界を `src/data/processes.ts` に保存。
- [公開資料とモデル範囲の一覧](docs/Fab15公開資料とモデル範囲.md) に日本語で整理。
- 公式拠点情報、広島の技術・製造に関する公式発表、所在地がFab15と明記された公式求人、Fab15の過去の認証証書を利用。
- 期限の切れた証書は過去の公開記録として扱い、現在有効な認証や現行の操業状態の証明とは扱わない。
- EUVの発表は該当する公開発表の範囲で説明。すべての露光がEUVであるとの断定や露光装置の機種・配置の推定は行わない。
- 装置メーカー等の一般資料を、Fab15の導入機種・実配置の根拠として利用しない。

## 保存する3Dモデル

`output/東広島Fab15_ウェーハ製造工程_公開資料模式モデル.glb` を読み込みます。アプリ内の「GLBを保存」でも再出力できます。

GLBには9工程区分の装置、FOUP、フロアを含め、日本語の工程名、公開資料、確認範囲、未確認事項をメタデータに保存します。画面の選択枠を除外した静止モデルです。Webアプリのラベル、説明パネル、工程デモのアニメーションはGLBに含まれません。`EXT_mesh_gpu_instancing` と `KHR_materials_emissive_strength` を使用します。

## 検証

```sh
npm test
npm run build
```

ビルドと既存の3件の再生テストが通過しました。内蔵ブラウザの1536×1024と390×844で、9区分の選択と根拠・未確認事項の表示、装置の直接クリック、回転、視点・ラベル切替、エッチング後の洗浄の再訪、デモ終端での停止、13資料の表示、スマートフォンでの資料ダイアログを確認しました。ページは正常に描画され、エラー表示や関連するコンソール警告・エラーはありませんでした。

出力GLBを再読込し、9工程区分と13資料のメタデータ、プローブ検査の過去記録区分、未確認事項、選択枠と後工程形状の除外を確認しました。これは表示とデータの検証であり、Fab15の実際の製造経路や装置を検証したものではありません。

## ソース構成

- `src/scene/buildFab.ts`：9工程区分の模式装置モデル。
- `src/scene/FabScene.tsx`：描画、回転、クリック、FOUP搬送、根拠情報付きGLB出力。
- `src/data/processes.ts`：日本語説明、公開資料、証拠区分、未確認事項、模式デモ経路。
- `src/hooks/useSimulation.ts`：再生状態と時間管理。
- `src/components/`：工程区分の選択、根拠・説明、ウェーハ模式図、再生操作。
- `design/spec.md`：画面と科学的表示の要件。
- `design/reference.png`：初期の汎用モデル用の視覚参考。Fab15の実装置・工場配置の資料ではなく、製品画面にも使用していない。
