# 東広島 Fab15 — DRAMウェーハ製造工程の3D学習モデル

マイクロンの公開資料を根拠に、東広島のFab15のウェーハ製造に関係する工程区分を学ぶ日本語・英語・中国語アプリです。公開資料で確認できる範囲、過去の公開記録、模式表現を工程ごとに区別します。マイクロンが公開した実工程図や工場配置図ではありません。

**工程順、反復回数、装置の外観・内部構造・寸法・台数、フロア配置、搬送経路、処理時間、ウェーハ断面、検査位置は説明用の模式表現です。実際の製造レシピ、装置メーカー・型番、実測値、歩留まりは再現していません。**

切断、組立、封止、パッケージ製品の最終試験は、このモデルの対象外です。この除外は、Fab15にそれらの工程が存在しないという断定ではありません。

## 起動する

Node.js 24とnpmで動作を確認しています。

```sh
npm install
npm run dev
```

開発用は `http://127.0.0.1:5173/`、ビルド済みのプレビューは `http://127.0.0.1:4173/` です。

```sh
npm run build
npm run preview
```

`dist/` が静的配信用のビルドです。HTMLを直接ダブルクリックせず、ローカルサーバーから開いてください。

## 使い方

- ヘッダーで昼・夜モードと日本語・English・中文を選択。工程名、装置ラベル、説明、模式図、公開資料の説明、操作名を切り替えます。
- 言語・昼夜を切り替えても、工程選択、再生位置、再生／停止、速度、ラベル表示、視点、開いた工程解説を保ちます。表示設定はブラウザに保存し、再読込後も使用します。
- 夜モードでは画面の配色と3D背景・床・照明を切り替えます。実工場の昼夜操業や照明条件を示すものではありません。
- ドラッグで回転、ホイール・ピンチで拡大縮小、右ドラッグで移動。
- 装置、ラベル、下部の工程区分を選ぶと、公開資料の根拠、未確認事項、学習用解説を表示。
- 黄色の「OHT搬送レール」と「FOUP搬送容器」の名札、または3Dのレール・容器を選ぶと、搬送・昇降とウェーハ保護の役割を3言語で表示。FOUPの名札は搬送中の容器を追い、狭い画面では引出線で位置を示します。
- 搬送設備の説明を開いても工程選択・再生位置・再生状態を保ちます。「工程の説明に戻る」で工程パネルへ戻ります。スマートフォンでは搬送設備を選ぶと説明パネルまでスクロールします。
- 「この工程に移動」で選択した装置を拡大。スマートフォンでは3Dビューまでスクロール。
- 「全体」「前工程」「プローブ」で視点を切り替え。「視点を戻す」で全体へ戻る。
- 再生・一時停止、前後の区間、再生位置、0.5×・1×・2×の速度を操作。
- 描画が中断された場合は進度の時計を止め、WebGLの復旧後に環境光・陰影を作り直します。言語、昼夜、工程選択、視点、再生／停止の意図を保ちます。自動で復旧しない場合は「3D表示を再試行」を選択できます。
- 「工程管理・DXの視点（一般例）」は学習用の一般的なデータ活用例。Fab15の実装を示すものではない。
- 「公開資料・確認範囲」で公開日、証書期限、確認内容、確認できない内容を表示。
- 同じダイアログに、以前の汎用DRAMモデルとの違いを3言語で表示。

## 収録する9つの工程区分

番号は分類用です。実際の工程順を示しません。

| 工程区分 | 主な模式表現 |
| --- | --- |
| ウェーハ搬送 | FOUP、ロードポート、OHT軌道と昇降部 |
| ウェット処理・洗浄 | ウェットステーション、槽、透明窓 |
| 薄膜形成 | 真空チャンバー、ウェーハ、配管 |
| フォトリソグラフィ | 露光装置、塗布現像ユニット |
| ドライエッチング | 処理チャンバー、ロードポート |
| 拡散・イオン注入・熱処理 | ビームライン、処理室、熱処理部 |
| CMP・平坦化 | 研磨ヘッドとパッド |
| 計測・欠陥検査 | 光学ヘッド、ウェーハステージ |
| プローブ検査 | プローブカード、チャック、画面 |

工程のつながりや反復を理解するための模式デモです。デモの経路は `src/data/processes.ts` の `DEMO_ROUTE` に定義します。Fab15の実処理順、回数、時間を推定したものではありません。OHTの台車は軌道上を移動し、FOUPの昇降部だけが上下します。搬送設備の構成自体も一般的な例です。

## 公開資料と確認範囲

- 工程ごとの根拠、公開日、確認日、確認内容、限界を `src/data/processes.ts` に保存。
- [公開資料とモデル範囲の一覧](docs/Fab15公開資料とモデル範囲.md) に日本語で整理。
- 公式拠点情報、広島の技術・製造に関する公式発表、所在地がFab15と明記された公式求人、Fab15の過去の認証証書を利用。
- 期限の切れた証書は過去の公開記録として扱い、現在有効な認証や現行の操業状態の証明とは扱わない。
- EUVの発表は該当する公開発表の範囲で説明。すべての露光がEUVであるとの断定や露光装置の機種・配置の推定は行わない。
- 装置メーカー等の一般資料を、Fab15の導入機種・実配置の根拠として利用しない。

## 保存する3Dモデル

`output/東広島Fab15_ウェーハ製造工程_公開資料模式モデル.glb` を読み込みます。アプリ内の「GLBを保存」でも再出力できます。

同梱GLBには9工程区分の装置、FOUP、フロアを含め、日本語の工程名、公開資料、確認範囲、未確認事項、OHT・FOUPの役割と模式表現の範囲をメタデータに保存します。アプリからの出力は選択中の言語を工程グループ名・説明メタデータ・ファイル名へ反映します。内部部品の検索用名は日本語を維持します。画面の選択枠を除外した静止モデルです。Webアプリのラベル、説明パネル、工程デモのアニメーションはGLBに含まれません。`EXT_mesh_gpu_instancing` と `KHR_materials_emissive_strength` を使用します。

画面は描画回数を減らす合成モデルを使い、保存時だけ共有ジオメトリを使う独立モデルを一時生成します。床の昼夜材質と可動部の保存時の姿勢を引き継ぎ、搬送台車は従来どおり最初の区画に戻して昇降部を格納します。出力の成功・失敗にかかわらず一時モデルを解放し、表示中のモデルには影響を与えません。GLBの縮小は保存・配布に有効です。画面はGLBを読み込まずコードから生成するため、GLBの縮小自体は首画面の読込時間を短縮しません。

## 描画負荷の抑制

- 一時停止中は画面を連続描画しません。再生、カメラ操作・移動、工程選択、停止中の位置調整、表示範囲、昼夜、言語、ラベル、サイズ・フォント変更で描画を再開し、動きが収まると停止します。非表示タブでは描画予約を解除します。
- ラベルのサイズは一括測定して保存し、言語・フォント・表示領域のサイズ変更時に更新します。毎フレームの寸法読み取りを避け、位置と表示状態が変わった要素だけ書き換えます。
- 同じ材質の不透明な静的部品を工程区分・OHT・各FOUPの範囲内で合成します。透明面、既存のインスタンス、可動部、選択枠は個別に維持し、クリックの意味とアニメーションを保ちます。

`http://127.0.0.1:4173/?perf=1` で `.scene-host` の `data-render-frames`、`data-render-calls`、`data-render-triangles`、`data-label-measurements` を読み取れます。通常表示では計測属性を更新しません。描画回数と測定回数はページ読込後の累計、callsとtrianglesは直近の描画値です。`buildFab({ optimizeStatic: false })` で合成前の形状と比較できます。

## 検証

```sh
npm test
npm run build
```

WebGL復旧と保存モデルの分離では、復旧イベントの重複・失敗・再試行・破棄、表示可否とタブ非表示の独立制御、環境光の生成失敗時の状態復元とリソース解放、保存成功／失敗時の一時リソース解放を回帰検証します。実GLBを再読込し、形状範囲・三角形・昼夜の床材質・可動部姿勢と9工程／13資料／8個のFOUPを比較します。既存22件に13件を追加した35テストとビルドが通過しました。

内蔵ブラウザでは `WEBGL_lose_context` による中断・復旧を複数回確認しました。停止中の視点・進度保持、再試行ボタンからの復旧、再生中の時計停止と自動再開、中断中に一時停止を選んだ場合の停止維持、言語切替、390×844の再試行表示を確認しました。1536×1024の通常入口で三言語の保存が成功し、新しい警告・エラーはありませんでした。日本語GLBは8,524,404から4,242,524バイトへ約50%縮小し、表示用の合成モデルは維持しています。

描画負荷の改善では、既存5件に描画予約9件、ラベル3件、静的合成5件を加えた22テストとビルドが通過しました。静的合成の検証には材質別の三角形、各工程の形状範囲、透明面・インスタンスの保持、実形状のクリック判定、可動部・ケーブル、GLBメタデータ、ジオメトリの解放を含みます。日本語GLBを再読込して形状範囲と三角形を比較し、3言語のGLBで9工程・13資料・搬送説明2件と選択枠の除外を確認しました。

内蔵ブラウザの1536×1024、全体表示・日本語・夜モードで、1フレームの描画呼出しは602から310へ減少し、描画された三角形は123,804で一致しました。停止時の連続描画は、この環境で約120回／秒から静止後0回へ変わりました。再生・終端停止・再生し直し、同一工程内の停止中の位置調整、回転・拡大・視点切替、言語・昼夜、ラベル表示、搬送説明を確認しました。描画中も寸法の測定回数は増えず、言語・サイズ変更後に更新されます。これは同一環境の呼出し数の比較であり、他のGPUやFPS向上率の測定ではありません。

390×844と320×740でも名札、引出線、三言語の説明と操作、説明パネルへの移動、ラベルの画面内配置を確認しました。ページ全体の横方向のはみ出しや、関連するブラウザのコンソール警告・エラーはありませんでした。

静的合成の代償として、表示用ジオメトリのデータ量が増えます。合成モデルを直接保存していた版のGLBは4.24 MBから8.52 MBへ増加しましたが、現在は保存用モデルを分けて約4.24 MBに抑えています。Node.js 24で8回の暖機後の `buildFab` 計測では中位値が28.87 msから59.20 msへ増加しました。この計測にはDOM、WebGL、シェーダ生成、描画を含みません。拡大時の可視範囲判定も部品単位から材質バッチ単位になり、細かいカリングは減ります。

昼夜・3言語対応では、再生3件と翻訳・根拠情報2件の計5テスト、およびTypeScript／Viteビルドが通過しました。内蔵ブラウザの1536×1024、390×844、320×740で表示を確認し、三言語の9工程区分と13資料、昼夜の3D表示、切り替え時の工程・再生位置・速度・再生状態・開いた工程解説・視点の保持、表示設定の再読込、英語・中国語のGLB出力を確認しました。関連するコンソール警告・エラーはありませんでした。他のブラウザやGPU環境は未検証です。

OHT・FOUPの名札追加では、同じ5テストとビルドが通過しました。1536×1024、390×844、320×740で三言語の名札と説明、昼夜の視認性、実形状のクリック、FOUP名札の移動、名札の表示切替、スマートフォンでの説明へのスクロール、再生中のクリックによる状態保持、工程説明への復帰を確認しました。関連するコンソール警告・エラーはありませんでした。日本語GLBの搬送説明2件、FOUPグループ8件、工程9件・資料13件の保持と選択枠の除外も確認しました。

ビルドと既存の3件の再生テストが通過しました。内蔵ブラウザの1536×1024と390×844で、9区分の選択と根拠・未確認事項の表示、装置の直接クリック、回転、視点・ラベル切替、エッチング後の洗浄の再訪、デモ終端での停止、13資料の表示、スマートフォンでの資料ダイアログを確認しました。ページは正常に描画され、エラー表示や関連するコンソール警告・エラーはありませんでした。

出力GLBを再読込し、9工程区分と13資料のメタデータ、プローブ検査の過去記録区分、未確認事項、選択枠と後工程形状の除外を確認しました。これは表示とデータの検証であり、Fab15の実際の製造経路や装置を検証したものではありません。

## ソース構成

- `src/scene/buildFab.ts`：9工程区分の模式装置モデル。
- `src/scene/FabScene.tsx`：描画、回転、クリック、FOUP搬送、根拠情報付きGLB出力。
- `src/lib/demandLoop.ts`：必要なときだけ動く描画予約と非表示・破棄処理。
- `src/lib/contextRecovery.ts`：WebGL中断・復旧・再試行、破棄済みの復旧結果の無効化。
- `src/scene/exportFab.ts`：共有ジオメトリを使う保存用モデルと一時リソースの解放。
- `src/scene/createEnvironment.ts`：環境光の生成、失敗時の描画状態とリソースの後始末。
- `src/scene/sceneLabels.ts`：ラベル寸法のキャッシュ、投影、衝突回避、一括DOM更新。
- `src/scene/optimizeStaticMeshes.ts`：意味区分を保つ不透明な静的部品の合成。
- `src/data/processes.ts`：日本語説明、公開資料、証拠区分、未確認事項、模式デモ経路。
- `src/data/localizedProcesses.ts`：英語・中国語の工程と資料の説明。ID、URL、証拠区分は日本語原データと共有。
- `src/data/transport.ts`：OHT・FOUPの3言語ラベル、役割、模式表現の範囲。
- `src/i18n/`：3言語の画面文言と、ブラウザ内に保存する言語・昼夜設定。
- `src/hooks/useSimulation.ts`：再生状態と時間管理。
- `src/components/`：工程区分の選択、根拠・説明、ウェーハ模式図、再生操作。
- `design/spec.md`：画面と科学的表示の要件。
- `design/reference.png`：初期の汎用モデル用の視覚参考。Fab15の実装置・工場配置の資料ではなく、製品画面にも使用していない。
