## 9つの分類と証拠表示

0：ウェーハ搬送・保管

1：ウェット処理・洗浄

2：多層膜の堆積

3：フォトリソグラフィ

4：高アスペクト比エッチング

5：メモリセル・電極形成

6：CMP・平坦化

7：CBA・ウェーハ貼り合わせ

8：ウェーハ検査・電気評価

0～7の「公開資料で確認」は、それぞれの工程分野または公開技術の記載に対応します。図に描いた装置の実在、実配置、処理条件を確認した表示ではありません。8は「模式表現・学習用補助」とし、プローバ・テスタによる接触検査の図を四日市の現行量産工程の証拠として扱いません。検査・計測・電気評価の役割をまとめて説明する区画です。

CBAでは、メモリセルアレイ用ウェーハとCMOS回路用ウェーハを別々に製造する分岐を説明します。図示した2枚、接合部、層数、断面は模式表現です。このウェーハ段階の接合は、完成チップのパッケージ積層を描いたものではありません。

## 搬送と学習用経路

自動搬送の根拠IDは `kioxia-yokkaichi-smart`。OHTの工程カテゴリーは公式説明で確認できます。描画したOHTの寸法・台車・昇降機構・軌道、FOUPの型式・容量は確認できていないため模式表現とします。

```text
搬送 → Wet → 多層膜 → リソグラフィ → メモリホール加工 → Wet
→ セル・電極形成 → CMP → CBA → 検査・電気評価
```

この10区間は役割を理解するための経路です。9分類は工場の装置数や実工程数ではありません。CMOS側の全工程、実際の反復・分岐・工程順序・所要時間は公開資料から再構成していません。CBAをすべての世代に共通する工程として扱わず、実際のプローブ検査の範囲や順序も推定しません。品質・DXの説明と架空の検査マップは学習用です。切断・パッケージ組立・最終製品検査は対象外です。

## データの入口

`src/data/kioxiaProcesses.ts` は `getKioxiaProcessContent(locale)` を提供し、日本語・英語・中国語の同じ9分類、8資料、根拠IDを返します。`KIOXIA_DEMO_ROUTE` は上記の10区間、`KIOXIA_TRANSPORT_SOURCE_IDS` は搬送根拠のIDです。既存のマイクロン資料とは独立して管理します。
