# Fab15 公開資料学習モデル — 表示要件

白地、紺色の文字、青緑の操作部、淡い灰青色の3D背景を維持する。デスクトップでは3Dビューと説明パネルを横に配置し、スマートフォンでは3Dビュー、再生操作、工程区分一覧、説明パネルを縦に配置する。

見出しは「東広島 Fab15」、対象はDRAMウェーハ製造。切断、組立、封止、パッケージ製品の最終試験の装置・アニメーションを表示しない。収録数は9工程区分。番号は分類用であり、実工程順ではないことを一覧にも明記する。

画面上部に、工程区分は公開資料に基づく一方、順序、反復回数、装置形状、配置、時間は模式表現であることを常時表示する。各工程のパネルには公開根拠、確認範囲、未確認事項、資料リンクを表示する。実際のFab15に関する事実と一般的な工程解説・品質管理・DXの例を区別する。

3Dはメーカーを特定しない手続き型の形状を使用する。配置は見やすさを優先した二列の学習用配置。FOUPとOHTの動きは模式例であり、実際のFab15の搬送経路・設備構成を示さない。ウェーハ模式図は実断面や実測値ではなく、検査位置の表示も例示である。

工程区分を選択し、対応する根拠情報を読むことが主な操作経路。回転・移動・拡大、装置のクリック、ラベルの表示、視点切替、選択装置への移動、模式デモの再生・停止・速度・送り・位置調整、資料ダイアログ、GLB出力を維持する。

GLBは9分類の静止形状と日本語の根拠・模式表現のメタデータを含む。Webの選択枠を含めず、後工程の形状を残さない。

`reference.png` は初期の汎用モデルの視覚参考である。Fab15の公開根拠、実装置、実レイアウトとして利用しない。現在の受入条件は本ファイルと工程ごとの公開資料に基づく。
