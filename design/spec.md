# Fab15 公開資料学習モデル — 表示要件

昼モードは白地、紺色の文字、青緑の操作部、淡い灰青色の3D背景を維持する。夜モードは深い紺色の背景と明るい文字を使い、3D背景・床・照明も調整して装置の形状を読み取れるようにする。昼夜表示は実工場の操業や照明条件を示さない。デスクトップでは3Dビューと説明パネルを横に配置し、スマートフォンでは3Dビュー、再生操作、工程区分一覧、説明パネルを縦に配置する。

日本語・英語・中国語の表示をヘッダーで選択する。工程名、説明、根拠、未確認事項、資料解説、模式図、操作・アクセシビリティ名をすべて切り替える。原資料へのリンクは共通。言語・昼夜切り替えで3D描画を作り直さず、工程選択、再生位置・状態・速度、視点、ラベル表示、開いた工程解説を保つ。表示設定はブラウザに保存する。

見出しは「東広島 Fab15」、対象はDRAMウェーハ製造。切断、組立、封止、パッケージ製品の最終試験の装置・アニメーションを表示しない。収録数は9工程区分。番号は分類用であり、実工程順ではないことを一覧にも明記する。

画面上部に、工程区分は公開資料に基づく一方、順序、反復回数、装置形状、配置、時間は模式表現であることを常時表示する。各工程のパネルには公開根拠、確認範囲、未確認事項、資料リンクを表示する。実際のFab15に関する事実と一般的な工程解説・品質管理・DXの例を区別する。

3Dはメーカーを特定しない手続き型の形状を使用する。配置は見やすさを優先した二列の学習用配置。FOUPとOHTの動きは模式例であり、実際のFab15の搬送経路・設備構成を示さない。ウェーハ模式図は実断面や実測値ではなく、検査位置の表示も例示である。

工程区分を選択し、対応する根拠情報を読むことが主な操作経路。回転・移動・拡大、装置のクリック、ラベルの表示、視点切替、選択装置への移動、模式デモの再生・停止・速度・送り・位置調整、資料ダイアログ、GLB出力を維持する。

OHTレールとFOUPに独立したクリック可能な名札を付ける。FOUP名札は搬送中の容器を追従し、名札の衝突を避ける。狭い画面や表示位置の補正時は引出線を使う。名札と実形状のクリックから搬送設備の説明を表示し、工程選択・再生位置・状態は変えない。日本語・英語・中国語の名前、役割、受け渡し例、模式表現の注意書き、戻る操作を用意し、昼夜の両方で読める配色とする。公開AMHS資料は職務範囲の根拠であり、黄色のレール構成や特定のFOUP型式の確認資料として扱わない。

停止中は必要なときだけ描画する。再生開始・終了、同一工程内の位置調整、視点の移動・減衰、選択、表示・言語・昼夜・ラベル・画面サイズ・フォント変更で描画を更新し、非表示タブでは予約を停止する。ラベル寸法は変更時だけ一括測定し、通常フレームは投影と変更箇所の更新だけを行う。

静的な不透明部品は同じ工程区分・搬送設備・個別FOUP内で材質ごとに合成できる。透明面のソート、既存のインスタンス、可動部、工程とFOUPのクリック判定、床の昼夜切替を維持する。合成前後で三角形と形状の範囲を検証する。

GLBは9分類の静止形状と根拠・模式表現のメタデータを含む。同梱ファイルは日本語。画面から出力する工程グループ名と説明メタデータは選択中の言語を使う。可動部の検索用名は日本語を維持し、合成した部品の元の名前と変換行列はバッチのメタデータに保存する。Webの選択枠を含めず、後工程の形状を残さない。

`reference.png` は初期の汎用モデルの視覚参考である。Fab15の公開根拠、実装置、実レイアウトとして利用しない。現在の受入条件は本ファイルと工程ごとの公開資料に基づく。
